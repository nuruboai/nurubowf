# nurubowf — ブロック型承認ワークフロー 試作版の入口

- 入口: https://nuruboai.com/nurubowf/ （github.io からも転送されます）
- ここでログインすると、ワークフローの画面（GASベータ版・Google Apps Script）へ移ります。向こうでもう一度ログインはしません。
- **本物の名前や情報は入れないでください。** お試し期間（2週間）が終わったら、入れたデータはまとめて消します。

## しくみ（1回のログイン）

1. 入口（`index.html`）で、お渡ししたIDとパスワードを Supabase で確かめる（`wf_login`）。
2. 使い捨ての札を1枚作る（`wf_ticket`、2分で切れる・1回だけ）。
3. GASベータ版の URL に札を付けて移る。GAS は合言葉つきで札を確かめ（`wf_redeem`）、決めてある職員として入れる。

- Supabase 側: `supabase/setup.sql`（アカウントとログイン）、`supabase/sso.sql`（札）。表には直接さわれず、関数だけを呼べます。
- テスト用アカウントと合言葉は、このリポジトリには入れていません。
