# nurubowf — ブロック型承認ワークフロー 試作版（Web公開版）

箱（受付・確認・決裁・合議など）を並べて承認ルートを作る試作を、Webで公開して、何人かで同時に試すためのものです。

- 公開先: https://nuruboai.github.io/nurubowf/
- 入り方: お渡ししたログインIDとパスワードで入り、「操作する人」で自分の役を選びます。役はいつでも替えられます。
- **本物の名前や情報は入れないでください。** お試し期間（2週間）が終わったら、入れたデータはまとめて消します。

## しくみ

- 画面と仕組み（`src/`）は試作 v14（block-workflow-proto）をもとにしています。タブの間の同期と「2人で試す」をやめ、ログイン画面と共有の保存場所につなぎ替えました。
- 共有の保存場所は Supabase です。表には直接さわれず、`supabase/setup.sql` の関数だけを呼べます。
  - 書くときは、最新を読み直してから仕組みを動かし、読んだ版のままなら保存します。先に誰かが書いていたら、読み直してやり直します。
  - ほかの人が書いたら、3秒ほどで画面に出ます。
  - 操作の記録（`wf_log`）は書き足すだけで、書き換え・削除はできません。
  - 「最初に戻す」は管理用のアカウントだけができます。
- テスト用アカウントはこのリポジトリには入れていません。

## 作り直し方

```
node tools/build-web.mjs   # src/ から index.html を作る
```
